**Thiran** (திறன் - efficiency in [Tamil](https://en.wikipedia.org/wiki/Tamil_language)) is a Spring inspired flexible and efficient configuration manager. It supports loading, merging, hydrating and validating configuration with bring your own validator that supports [Standard Schema](https://standardschema.dev/).

For more details, refer [here](https://prasanna-ramesh.github.io/thiran/).
